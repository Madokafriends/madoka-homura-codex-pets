# Contributing

Thanks for helping improve this fan-made Pets collection.

## Before opening an issue

- Confirm the problem occurs with the unmodified `spritesheet.png` from this repository.
- Include the affected pet, ChatGPT surface, app version, and a short reproduction description.
- Do not attach account data, private conversations, access tokens, or other sensitive information.

## Pull requests

1. Create a focused branch and keep each pull request limited to one concern.
2. Preserve the v2 `1536 × 2288` transparent PNG layout and existing character identity.
3. Run the official ChatGPT Pets validation before proposing any sprite-sheet replacement.
4. Run `python scripts/generate_previews.py` and commit regenerated previews and metadata.
5. Explain the artwork provenance and confirm that you have the right to contribute it.

Submissions containing unlicensed third-party assets, unrelated generated content, or commercial branding may be closed without merge.
